# Практическая работа №12. Добавление загрузки файлов в веб-приложение

**Вариант №3:** Электронная библиотека (PDF + обложка книги)

## Описание проекта
Веб-приложение для загрузки, хранения и просмотра электронных книг в формате PDF с обложками.

### Реализованный функционал:
- **Загрузка нескольких файлов (`FormData` + `Multer`):** одновременная отправка изображения обложки (`JPG`, `PNG`, `WEBP` до 2 МБ) и файла книги (`PDF` до 15 МБ) вместе с текстовыми полями (название книги и автор).
- **Предпросмотр и прогресс-бар:** отображение превью обложки до отправки через `URL.createObjectURL`, вывод размера выбранного PDF-файла и индикатор прогресса загрузки в процентах (`<progress>` через `XMLHttpRequest`).
- **Валидация на клиенте и сервере:** проверка MIME-типов и максимального размера файлов.
- **Хранение данных в PostgreSQL:** файлы сохраняются в директорию `server/uploads`, а метаданные (название, автор, пути к файлам, размер PDF) записываются в таблицу `public.books`.
- **Каталог и удаление:** вывод списка загруженных книг, открытие PDF для чтения в новой вкладке и удаление книги вместе с физическими файлами с сервера.

## Стек технологий
- **Frontend:** React, Vite, CSS3, XMLHttpRequest / Fetch API
- **Backend:** Node.js, Express, Multer, CORS
- **База данных:** PostgreSQL (`pg`)

## Подготовка базы данных (PostgreSQL)
Перед первым запуском выполните SQL-запрос для создания таблицы:

```sql
CREATE TABLE IF NOT EXISTS public.books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  author VARCHAR(255) NOT NULL,
  cover_url TEXT NOT NULL,
  pdf_url TEXT NOT NULL,
  pdf_size INTEGER NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

*(В файле `server/server.js` в настройках `Pool` укажите ваш пароль от базы данных PostgreSQL).*

## Команды для запуска проекта

### 1. Запуск серверной части
Откройте первый терминал и выполните:
```bash
cd server
npm install
node server.js
```
Сервер запустится по адресу: `http://localhost:3000`

### 2. Запуск клиентской части
Откройте второй терминал и выполните:
```bash
cd client
npm install
npm run dev
```
Клиент запустится по адресу: `http://localhost:5173`
